# حاسبة أجر الساعة

راتبك الشهري يساوي كام في الساعة فعلًا؟ وقارن بين عرضين

**رابط الأداة (تعمل فورًا من المتصفح):** https://abood-ayman.github.io/hourly-wage-ar/

## ما الذي تقدمه؟

- أجر الساعة واليوم والأسبوع من راتبك الشهري وساعات عملك
- مقارنة عرضي عمل جنبًا إلى جنب بأجر الساعة الحقيقي
- تعتمد متوسط السنة (٥٢ أسبوعًا ÷ ١٢ شهرًا) وليس حسابًا تقريبيًا مضللًا
- مفيدة عند المفاضلة بين وظيفة بدوام وشغل حر بالساعة

## الخصوصية

تعمل الأداة بالكامل داخل متصفحك (HTML/CSS/JavaScript فقط). لا يوجد خادم، ولا حسابات، ولا تتبّع، ولا تُرسل أو تُحفظ أي بيانات تدخلها خارج جهازك.

## التقنية

صفحة ثابتة واحدة بلا أي مكتبات خارجية، تعمل على الهاتف والحاسوب، وتُستضاف مجانًا عبر GitHub Pages.

## ملاحظة شفافية

بُنيت هذه الأداة بمساعدة أدوات ذكاء اصطناعي، ورُوعيَت بساطتها وفائدتها المباشرة.
