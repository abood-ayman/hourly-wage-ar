# Hourly Wage Calculator | حاسبة أجر الساعة

Convert a monthly salary into real hourly, daily and weekly pay, and compare two job offers side by side. Arabic interface.

**Live app:** https://abood-ayman.github.io/hourly-wage-ar/

![Hourly Wage Calculator, mobile view](docs/screenshot.svg)

This is a personal project, built with AI tools.

## Features
- Hourly, daily and weekly pay from monthly salary and work hours
- Compare two offers side by side by real hourly rate
- Uses the true year average (52 weeks / 12 months), not a rough shortcut
- Useful when weighing a full-time job against freelance hourly work

## Privacy
Everything runs in your browser. No data is stored or sent anywhere.

## Run locally
Open `index.html` in any browser. It is a single static page with no dependencies.
